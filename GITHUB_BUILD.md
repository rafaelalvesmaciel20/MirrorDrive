# MirrorDrive — build pelo Samsung S21 FE

1. Crie um repositório vazio no GitHub.
2. Use Add file → Upload files e envie os arquivos deste projeto, mantendo a estrutura.
3. Faça commit na branch `main`.
4. Abra Actions.
5. Selecione “Build MirrorDrive APK”.
6. Toque em “Run workflow” (ou faça um commit para dispará-lo).
7. Aguarde o build.
8. Abra a execução concluída e, em Artifacts, baixe “MirrorDrive-debug-apk”.
9. Extraia o ZIP do artifact e instale o APK no S21 FE.

O workflow usa Ubuntu, JDK 17 e Android SDK na nuvem; não exige Windows.
